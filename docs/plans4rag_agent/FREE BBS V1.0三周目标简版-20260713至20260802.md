# FREE BBS V1.0 三周目标简版

> 周期：2026 年 7 月 13 日至 8 月 2 日

## 四个组要完成什么

| 小组 | 三周目标 |
| --- | --- |
| Agent组 | 完成 Max、RAG-Agent、工作管家 Agent、监管 Agent 的基础功能，并接入产品主要页面。 |
| 开发组 | 完成主页、课程地图、知识点学习、讨论与树洞、个人工作区、个性化学习记录、签到与激励系统的可用 Alpha。 |
| 课程组 | 完成微积分、电子电路与系统基础、数字逻辑与处理器基础、信号与系统四门课程可导入的知识点清单、课程内关系和跨课程关联。 |
| 调研组 | 调研成熟产品及四类 Agent 的实现方式，向 Agent组和开发组提交可以直接采用的产品与交互建议。 |

## 三周后的产品应该是什么样子

三周后，FREE BBS 应形成一个可以完整演示的 V1.0 Alpha：

- 用户可以登录平台，从主页进入课程学习、讨论、个人工作区和 Max；
- 四门课程能够展示课程知识图谱，用户可以进入具体知识点学习；
- 用户可以调用 RAG-Agent 提问、完成快速自测，并查看学习记录；
- 用户可以在知识讨论区或匿名树洞发帖、回复，并由监管 Agent 辅助审核；
- 用户可以查看分类通知和个人时间表，由工作管家 Agent 提供信息与时间规划建议；
- 用户可以签到，并看到基础的电元、磁元、成就和商城功能；
- 主要功能能够相互跳转，权限和关键操作可以追溯，系统具备继续联调和测试的基础。
