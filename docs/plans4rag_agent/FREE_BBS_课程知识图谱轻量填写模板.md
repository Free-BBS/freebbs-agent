# FREE BBS 课程知识图谱轻量填写模板

> 用途：供课程整理人填写课程、章节、知识点、关系与资料依据。  
> 转换规则：本文件字段与 `FREE_BBS_课程知识图谱轻量模板.json` 一一对应；JSON 是批量导入时的标准数据。  
> 填写原则：一个文件只填写一门课程；先列知识点，再填写关系；所有关系和资料均通过 ID 引用。

## 0. 填写约定

### 必填标记

- `【必填】`：缺失时不得导入。
- `【条件必填】`：满足条件时必须填写。
- `【选填】`：可以留空，JSON 中使用空数组 `[]`、空字符串 `""` 或 `null`，不要填写“无”。

### ID 规则

- 课程 ID：大写英文缩写，比如 `信号与系统: SS`。
- 章节 ID：`课程ID-ch序号`，如 `SS-ch03`。
- 知识点 ID：`课程ID-kp序号`，如 `SS-kp-0301`。
- 资料 ID：`课程ID-mat序号`，如 `SS-mat-001`。
- ID 创建后保持稳定；名称修改时不要修改 ID。

### 固定枚举

- 节点类型 `node_type`：`core` 核心、`general` 一般、`extended` 拓展。
- 难度 `difficulty`：`1` 简单、`2` 较难、`3` 很难。
- 关系类型 `relation_type`：
  - `prerequisite`：源知识点是目标知识点的前置；
  - `application`：源知识点应用于目标知识点或应用场景；
  - `related`：一般相关；
  - `confusable`：容易混淆；
  - `same_entity_candidate`：可能对应同一个跨课程知识实体。（比如不同的课程中FT不同的定义）
- 关系范围 `scope`：`within_course` 课程内、`cross_course` 跨课程。
- 来源层级 `source_level`：
  - `official_text`：官方正文、教学大纲；
  - `course_material`：教材、讲义、课件；
  - `quality_discussion`：审核后的优质讨论；
  - `extended_content`：拓展资料（比如小班辅导资料等）；
- 审核状态 `review_status`：`draft` 草稿、`reviewed` 已复核。
